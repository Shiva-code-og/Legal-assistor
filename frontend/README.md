# Frontend

All React UI code lives in `../src/`:

- `../src/main.tsx` — App entry point
- `../src/App.tsx` — Root component & routing
- `../src/index.css` — Global Tailwind styles
- `../src/types.ts` — Shared TypeScript types
- `../src/components/` — All UI page and component files
- `../src/data/` — Static data (Indian states/districts)
- `../index.html` — Vite HTML shell

**Tech:** React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React
